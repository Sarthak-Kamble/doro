# 🍅 Doro

A simple and lightweight **Pomodoro Timer CLI** built with Go.

Doro helps you stay focused by running timed work sessions directly from your terminal.

---

## ✨ Features

- 🚀 Start Pomodoro sessions from the terminal
- ⏱️ Custom session duration
- 🏷️ CLI version information
- 📖 Built-in help commands
- ⚡ Fast and lightweight (written in Go)

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Sarthak-Kamble/doro
```
